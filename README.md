# Smart Maintenance

설비 예방점검 · 고장 · 정비 이력을 한곳에서 관리하는 **브라우저 기반 설비보전 웹 애플리케이션**입니다.

## 실행 및 데모

- [공개 데모](https://smart-maintenance-aleph.vercel.app/) — 기존 Vercel 배포본입니다. GitHub에 등록한 소스와 배포 버전은 다를 수 있습니다.
- `index.html`은 별도 설치가 필요 없는 단일 HTML 버전입니다.
- Windows에서 기존 기록을 유지하며 실행하려면 별도 제공된 통합 원본의 `SmartMaintenance-Start.cmd`를 실행해 **동일한 주소와 브라우저 프로필**을 사용해야 합니다.

## 주요 기능

- 설비 등록 및 점검표 관리
- 일·주·월·연 예방점검 계획 및 일정 표시
- 정상·주의·고장 판정과 점검 이력
- 고장 등록, 정비 작업과 처리 이력 연결
- 현장 사진 첨부
- IndexedDB 로컬 저장 및 암호화 백업·복원
- PC·모바일 탐색 UI

## 데이터 및 안전 안내

**이 저장소에는 사용자가 입력한 설비·점검 데이터가 들어 있지 않습니다.**
실제 데이터는 실행한 브라우저의 IndexedDB에 저장됩니다. 다른 URL, 브라우저 프로필, 기기에서는 자동 공유되지 않습니다. 사용 전후로 앱에서 백업 파일을 별도 보관하세요.

## 기술

HTML, CSS, JavaScript, 브라우저 IndexedDB. 서버나 클라우드 DB를 사용하지 않는 로컬 우선 구조입니다.

## 개발 상태

개인 프로젝트 프로토타입입니다. 주요 업무 흐름과 회귀 테스트를 구현했으나 모든 브라우저·기기 조합에서의 실사용 통합 검증을 완료한 상태는 아닙니다. 공개 데모와 로컬 소스의 버전 차이에 주의하세요.
